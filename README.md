# Root Structure – Shear Box Experiments

This repository provides the Blender model of the synthetic root structure used in the shear box experiments described in the publication below.

## Related publication

Sorrentino, Gianmario; Reinertsen, Jørgen A.; Skar Christiansen, Asmus; Rasmussen, Ian (2026). *Direct measurement of shear mobilisation in 3D-printed root analogues using distributed fibre-optic sensing.*

**DOI:** [10.1139/cgj-2026-0606](https://doi.org/10.1139/cgj-2026-0606)

Please cite this publication when using the model in your research.

## Model download

The Blender file, `root_structure.blend`, is available from [GitHub Releases (v1.0)](https://github.com/jorei123/Root_Structure/releases/tag/v1.0).
